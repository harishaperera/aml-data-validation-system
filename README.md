# AI-Driven Financial Crime Risk Intelligence & Transaction Monitoring System

## 1. Project Overview

This project aims to develop an automated data profiling, cleaning, validation and anomaly detection system specialised in Financial Crime Compliance (FCC) and Anti-Money Laundering (AML).

The project uses synthetic banking transaction data for development and testing.

## 2. Project Objectives

- Identify missing and invalid transaction data.
- Detect duplicate transaction records.
- Analyse transaction data quality.
- Apply automated data validation rules.
- Explore machine learning-based anomaly detection.
- Generate structured data quality reports.

## 3. Project Modules

### Module 1 – Advanced Data Profiling

- Synthetic banking transaction dataset.
- Missing value detection.
- Duplicate transaction detection.
- Invalid amount detection.
- Column-level data profiling.
- Data quality score calculation.
- JSON profiling report generation.

### Module 2 – Automated Data Cleaning

- Data standardisation.
- Missing value handling.
- Duplicate management.
- Data transformation.
- Cleaning logs.
- Cleaned CSV output.

### Module 3 – AI Validation and Anomaly Detection

- Rule-based validation.
- Anomaly detection.
- Transaction pattern analysis.
- Validation reports.

### Module 4 – Integration and Production Engineering

- End-to-end pipeline.
- Testing and documentation.
- Docker integration.
- Final project demonstration.

## 4. Technology Stack

- Python
- Google Colab
- GitHub
- JSON

## 5. Data Privacy and Governance

This project uses synthetic data only. No real customer information, confidential banking information or actual financial crime investigation records are used.

The system is designed to support human review and does not independently determine criminal activity.

## 6. Current Project Status

Module 1 – Advanced Data Profiling: Initial implementation completed.

Further advanced profiling capabilities are under development.

## 7. Disclaimer

This is an educational prototype for data quality management and financial crime compliance technology. It does not replace professional AML investigations, regulatory requirements or human decision-making.
